# DSH万用壁纸补丁 · 使用说明

**只需要一个文件：`DSH万用壁纸补丁.exe`**（约 420 KB）。

整个皮肤包（插件代码 + 页面脚本 + 配置 + 文档 + 授权）已经**内嵌在这个 exe 里面**了，
所以不用再单独装皮肤包、也不用手工改 YAML。

- 绿色单文件，**双击即用**，不写注册表、不需要安装任何运行时
- 只依赖 Windows 自带的 .NET Framework 4.x（Win10 / Win11 都有）
- 自动探测**对方自己的**路径，**没有任何写死的路径**，可以直接发给别人

---

## 一分钟上手

1. 双击 `DSH万用壁纸补丁.exe`
2. 点 **「一键安装皮肤」**
   - 它会释放内嵌文件 → 登记依赖 → 写入配置
   - 如果此时 DSH 正开着，它会**提示并自动关掉 DSH、装完再拉起**（原因见下方 FAQ）
3. 装好后，DSH 界面**右下角**会出现一个小药丸：`● 壁纸：开`
4. **点它一下就能即时开关壁纸** —— 不用刷新、不用重启

## 界面按钮

| 按钮 | 作用 |
|---|---|
| **一键安装皮肤** | 释放内嵌皮肤包 + 登记依赖 + 写入配置（已装且同版本时会自动跳过，秒完成） |
| **卸载皮肤** | 注释掉配置里的皮肤块 + 删除释放的文件 + 移除依赖登记（随时可重装恢复） |
| **更换壁纸…** | 选一张本地图片（jpg/png/webp/gif/avif/bmp/svg），写入 `imagePath`，重启后生效 |
| **恢复默认壁纸** | 清空 `imagePath`，回退到内置渐变底 |
| **调节透明度…** | 打开 11 组「滑块 + 色块」：左边调不透明度，右边色块改该元素的底色 |
| **关闭壁纸 / 开启壁纸** | 改配置里的 `imageOpacity`（`0.95` ↔ `0`） |
| **停用皮肤 / 启用皮肤** | 把配置里那一段整体注释掉 / 恢复 |
| **应用并重启 DSH** | 结束并重新启动 DSH，让上面的改动立刻生效 |
| **只重启 DSH** | 不改配置，单纯重启 |
| **查看使用说明** | 打开内嵌在程序里的这份说明 |
| **打开皮肤文件夹** | 打开 `%USERPROFILE%\.dsh\skins\dsh-dream-skin` |

窗口顶部实时显示：**皮肤：已安装·已启用/已停用/未安装　壁纸：开/关**。

## 调节透明度与配色

点 **「调节透明度…」** 打开面板，一共 11 行，每行三件东西：

```
侧栏一级按钮    □□□□□□●□□□□   70%   [色块]
   ↑ 名称         ↑ 拖动条        ↑ 当前值  ↑ 该元素的底色
```

- **滑块**：0 最透（看不见底），100 最实（完全不透明）
- **色块**：点一下弹出取色器，给这个元素换一个专属底色；点「默认」清空，回到主题原本的中性色
- 改完点「保存」，再点主窗口的 **「应用并重启 DSH」** 生效

11 个元素分别是：主区面板、侧栏、侧栏一级按钮、列表条目、对话框、账户入口、
输入区、用户气泡、性能用量条、命令菜单、滚动条。

> 想手工改也可以：这些值就是 `cordis.patch.yml` 里的 `*Alpha`（0~1，不透明度）与
> `*Tint`（`#rrggbb`，留空＝主题中性色）两两组键，一一对应。

## 三种开关壁纸的方式

| 方式 | 生效速度 | 适合 |
|---|---|---|
| **右下角小药丸**（推荐） | **即时**，零等待 | 日常随时开关 |
| 程序里的「关闭/开启壁纸」 | 需要重启 DSH（程序会问你） | 想改默认状态 |
| 手工改配置文件 | 需要重启 DSH | 折腾参数 |

小药丸可以**拖动**到任意位置（位置会记住）；平时只有 40% 不透明度，鼠标移上去才变清晰；
状态与位置存在浏览器 localStorage 里，刷新后保持。

## 常见问题

**Q：为什么「一键安装」要关掉 DSH？**
因为 DSH 运行时**锁住了插件文件**（Windows 文件锁），覆盖写入会被拒绝。
程序会先尝试直接写；只有**确实需要写入**（版本不同）时才会关 DSH、写完再拉起。
如果内容完全一致（重复安装），它会直接跳过，**完全不动 DSH**。

**Q：按了按钮但界面没变化？**
皮肤是宿主侧插件，**改完必须让 DSH 重新加载**：点「应用并重启 DSH」，或自己重启。
右下角小药丸是唯一不需要重载的开关。

**Q：右下角没看到小药丸？**
确认两件事：① 皮肤已安装且**启用**；② **重启过一次 DSH**（插件代码是进程内加载的，刷新网页换不掉）。
配置项 `pageToggle: true` 控制是否注入这个小开关（默认开）。

**Q：小药丸跑到奇怪的位置了？**
拖回来就行。想复位：在 DSH 里按 F12，Console 执行
```js
localStorage.removeItem('dsh-dream-skin-toggle-pos'); location.reload();
```

**Q：卸载后想再装回来？**
再点一次「一键安装皮肤」即可 —— 文件都在 exe 里面，不需要原包。

**Q：会把我的配置改坏吗？**
不会。程序只做这些文本改动：替换 `imageOpacity:` 的数值、给皮肤那一段加/去行首 `# `、
在 `package.json` 里增删一行依赖。停用用的是注释，原始内容完整保留，取消注释即原样恢复。
（已实测：注释 → 取消注释**往返完全一致**。）

## 卸载

1. 程序里点「卸载皮肤」（会注释配置并删除释放的文件）
2. 删掉 `DSH万用壁纸补丁.exe` 本身即可（绿色程序，没有其它残留）
3. 彻底回滚（连配置一起恢复原样）：见 `手动应用与排错.md` 的「完全回滚」一节
